# UU — U Utils library

UU provides two fundamental container libraries: a generic vector `uu_vec` and a dictionary `uu_dict`, exposed via macros in `uu.h` with supporting implementation in `uu.c`.

UU 包含两种基础的容器库: 通用向量 `uu_vec` 和字典 `uu_dict`, 通过 `uu.h` 中的宏以及 `uu.c` 中的实现提供支持.

## Quick start / 快速开始

- Compiler requirements: the compiler must support GCC extensions `__typeof__` and statement expressions `({ ... })`.
- 编译器要求：需支持 GCC 扩展 `__typeof__` 和语句表达式 `({ ... })`.
